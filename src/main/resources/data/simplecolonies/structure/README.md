# Structure NBTs go here
Each culture has its own folder: `egyptian/`, `roman/`, `greek/`, `persian/`, `mesopotamian/`
Export from in-game with `/place template` or BlockBench -> save as .nbt.
Example path: `data/simplecolonies/structures/egyptian/town_hall_1.nbt`
Registered automatically via `CultureType.getStructure("town_hall_1")`
