## Progression Summary (new in 0.4.0)
See `docs/PROGRESSION.md` for full tree. TL;DR:
- **Tool tiers:** Wood→Stone→Iron→Diamond, each +30-40% work speed, gated by mats (miner must produce iron for Iron tier)
- **Profession unlocks:** Farmer+Lumberjack free, rest locked behind Tool Stone etc (Miner→Builder→Courier→Butcher→Leather→Blacksmith→Soldier→Baker)
- **Building levels:** each building 1 worker at Lv1, upgrades +1 worker/+2 size, needs base×level mats + culture tier mats (Greek wood→stone→terracotta→marble)
- **Create schematics:** put `create:schematic` item in village chest → Builder auto-pastes it (optional Create dep)

Rest of doc as before — colonies spawn with wood-tier starters and evolve using local resources.
